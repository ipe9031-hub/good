# 기능별 개발 현황

‘구현 완료’는 코드와 명시된 자동 검사 범위의 완료를 뜻합니다. Phase 1 전체의 Windows PowerPoint 실기 승인은 아직 받지 않았습니다.

| 기능 | 상태 | 검증 |
|---|---|---|
| 프로젝트 구조, 한국어 Task Pane, manifest, 리본 버튼 | 구현 완료 | 빌드/브라우저/로컬 manifest 검사, Windows 미검증 |
| 프레젠테이션·선택 슬라이드·선택 개체 읽기 | 구현 완료 | 모의 호스트 계약 테스트 |
| 텍스트 상자·기본 도형 4종·사진 삽입 | 구현 완료 | 모의 Office.js + 브라우저 통합 |
| 선택 개체 위치·크기 수정 및 삭제 | 구현 완료 | 대상 보호·미리보기·적용 테스트 |
| Windows 사이드로드 | 부분 구현 | 도구·manifest·절차 제공, Windows 실기 미실행 |
| 상용 배포, Vercel 실배포 | 개발 예정 | 설정 파일 및 배포 방법 제공 |
| Phase 2 기본 편집 도구 전체 | 개발 예정 | 아래 순서 권장 |
| Phase 3 GPT 생성·자연어·부분 수정·AI 마킹 | 개발 예정 | 서버 키·인증·명령 스키마부터 구현 |
| Phase 4 번역 3모드·이미지 편집 | 개발 예정 | 언어·범위·원본 보호 요구사항 유지 |
| Phase 5 자동화·문서 변환·선택적 복원 | 개발 예정 | 전체 요구사항 유지 |
| API 서버, Supabase 스키마·마이그레이션 | 개발 예정 | Phase 1에서는 데이터 저장/외부 AI 호출 없음 |

## Phase 2 권장 순서

1. Windows 실기 체크리스트 통과 및 발견된 호스트 차이 수정
2. 정밀 좌표/단위 변환, 경계 제한, 정렬·크기 통일
3. 도형 라이브러리, 유사 도형 검색과 대상 목록 미리보기
4. 일괄 속성 변경·삭제, 텍스트·색상 변경, 서식 복제
5. 사진 비율 유지·그리드 배치·맞교환·삭제 후 재배치

전체 기능과 제외 범위는 원문 `PRODUCT-REQUIREMENTS.ko.txt`를 기준으로 합니다. 템플릿 학습, AI 품질검사, 고급 표·차트, 애니메이션, 자동 명명/태그 관리, 독립 사진 설명 메뉴는 추가하지 않았습니다.
