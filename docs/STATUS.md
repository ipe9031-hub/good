# 기능별 개발 현황

현재 버전: v0.2.4 (Phase 2 기본 편집 도구). ‘구현 완료’는 아래 명시한 범위의 코드·자동 검증 완료입니다. Phase 1 기본 기능은 사용자가 실제 Windows PowerPoint에서 확인했다고 보고했습니다. Phase 2 새 기능은 실제 Windows에서 아직 검증하지 않았습니다.

| 기능 | 상태 | 검증/범위 |
|---|---|---|
| 리본·작업창·선택 인식·텍스트/도형/사진 삽입·위치/크기·삭제 | 구현 완료 | Phase 1 사용자 Windows 확인 + 자동 회귀 테스트 |
| 간결한 UI 및 일반 작업 한 번 적용 | 구현 완료 | 옵션 접기/펼치기, 이름·ID 목록 제거, 삭제/전체 변경은 개수·범위 확인 |
| 빠른 삽입 및 도형 라이브러리 UI | 사용자 요청으로 제거 | 기본 개체 추가는 PowerPoint 메뉴 사용, 어댑터 코드는 유지 |
| 크기 복제 및 찾기 후 배치 선택 | 구현 완료 | 정렬 6종·간격 2종·크기 복제, 독립 너비/높이/위치 복제 UI 제거 |
| mm/cm/pt 이동·경계 제한 | 구현 완료 | 단위/경계 알고리즘 테스트 |
| 사진 그리드·비율 유지·맞교환 | 구현 완료 | 개체 좌표 교환, 현재 개체 비율 유지 |
| 사진 삭제 후 재배치 | 구현 완료 | 애드인 삭제 작업에서 그리드/당기기/위치 유지, 대상 확인 |
| 전체 개체 조회·유사 조건·선택·색상 변경·삭제 | 부분 구현 | 선택 없이 도형·사진·텍스트 전체 조회, 종류 필터, 검색과 선택 한 번 실행, 자동 오차와 선택적 유형·단색 채우기·크기 조건. 세부 프리셋 형태/그룹 내부 제외 |
| 텍스트 일괄 서식·문구 바꾸기 | 구현 완료 | 선택/현재/전체 범위. 표·그룹 제외, placeholder는 API 1.10 |
| 스마트 색상 일괄 변경 | 부분 구현 | 단색 채우기·테두리·균일 글자색. 그룹·테마/그라데이션 완전 처리 제외 |
| 기본 서식 복제 | 부분 구현 | 단색·테두리 색/두께·균일 텍스트 서식, 내용/위치 유지 |
| 스마트 크롭·사진 내용만 교환·연결 설명문/마킹·원본 이미지 교체 | 개발 예정 | PHASE2.md의 제한 참조 |
| 고급 서식·그림자 복제 | 개발 예정 | 기본 서식만 제공 |
| Windows 배포형 사이드로드 | 구현 완료 | 사용자가 good-red.vercel.app 배포 후 실제 추가 기능 사용 확인 |

| 작업창 단축키 | 구현 완료 | 키 이벤트·입력 중 차단·중복 실행 방지 자동 테스트 |
| 슬라이드 포커스 전역 단축키 | 부분 구현 | 최신 Office용 별도 공유 런타임 manifest/JSON/Office.actions 제공, 실제 Windows 미검증 |
| Phase 3 GPT 생성·자연어·부분 수정·마킹 | 개발 예정 | 서버 키·인증·명령 스키마부터 |
