# Phase 2 — 기본 편집 도구 v0.2.3

2026-11-12. 기존 Phase 1 기능은 사용자가 Windows PowerPoint에서 동작을 확인했습니다. 아래 새 기능은 Linux 타입 검사·빌드·모의 Office 호스트 테스트로 검증했으며 Windows에서 별도 확인되지는 않았습니다.

## 화면과 적용 방식

상단 소개 배너, 홍보 문구, 장식 로고, 중복 데스크톱 레일을 제거했습니다. 작업 문서와 도구를 바로 표시합니다. 빠른 삽입 메뉴는 사용자 요청으로 제거했습니다. 개체 추가는 PowerPoint 기본 메뉴를 사용하고 위치·크기 변경은 클릭 한 번으로 적용합니다. 삭제, 사진 삭제 후 재배치, 전체 프레젠테이션의 일괄 변경만 확인창을 엽니다.

## 접히는 옵션과 간단한 화면

검색·배치 옵션, 미세 이동, 서식 복사, 텍스트 서식/문구/색상 도구는 기본적으로 접혀 있습니다. 각 박스 제목을 눌러 열고 다시 눌러 닫습니다. 개체 이름·ID·상세 결과 목록은 표시하지 않습니다. 삭제나 전체 변경 확인창도 개수와 범위만 표시하며 내부 대상 검증은 유지합니다.

## 정렬·크기

1. 같은 슬라이드에서 여러 개체를 선택합니다.
2. **편집 도구 → 정렬·크기**를 엽니다.
3. 기준 개체를 고르고 정렬·너비/높이 통일·크기/위치 복제를 실행합니다. 선택 순서를 Office가 제공하지 않으므로 기본 ‘첫 번째’는 API가 반환한 순서입니다. 기준 선택 메뉴로 명시할 수 있습니다.
4. 가로·세로 간격 균등 배분은 3개 이상이 필요합니다. 개체 크기의 합보다 영역이 좁으면 먼저 영역을 넓혀야 합니다.
5. 미세 이동은 pt/mm/cm 단위로 양수·음수를 입력합니다. 결과는 슬라이드 안으로 제한됩니다. 개체 자체가 슬라이드보다 크면 작업을 거부합니다.
6. 기본 서식 복사는 기준 개체 하나를 선택해 복사한 뒤 대상 개체를 골라 붙여넣습니다. 내용과 좌표는 바꾸지 않습니다.

실제 슬라이드 크기는 PowerPointApi 1.10에서 읽습니다. 구버전에서는 **슬라이드 크기 설정**을 열고 PowerPoint 디자인 → 슬라이드 크기에 맞는 너비·높이를 pt로 입력하세요. 1인치=72pt, 1cm≈28.346pt입니다. 기본 입력 960×540은 16:9의 예시이며 실제 문서 크기를 보장하지 않습니다.

## 사진 배치

현재 슬라이드에서 사진 개체만 선택합니다. 도형 채우기 이미지와 이미지 내부에 그려진 글자/도형은 별도 사진 개체가 아닙니다.

- **그리드 배치:** 선택 사진들의 기존 전체 영역 안에 열 수·간격을 기준으로 배치합니다. ‘현재 사진 비율 유지’는 개체의 현재 너비/높이 비율을 유지하며 셀 안에 맞춥니다. 원본 파일의 크롭 상태 복원이나 스마트 크롭을 뜻하지 않습니다.
- **맞교환:** 사진 정확히 두 개의 좌표를 교환합니다. 현재 개체 크기와 주변 설명문은 유지됩니다. 사진 내용만 교체하거나 마킹/설명을 함께 묶는 기능은 포함하지 않습니다.
- **삭제 후 재배치:** 삭제할 사진과 남길 사진을 함께 선택하고 삭제 대상 메뉴에서 한 개를 고릅니다. 빈 공간을 그리드로 채우거나, 기존 크기로 앞자리로 당기거나, 기존 위치를 유지할 수 있습니다. 확인창에는 삭제 개수와 작업 범위만 표시합니다.
- 이 자동 재배치는 애드인 안의 삭제 작업에서 실행됩니다. PowerPoint 기본 Delete 키로 삭제하는 이벤트를 가로채지 않습니다.

## 개체 검색 및 유사 조건

기본 검색은 선택 없이 도형·사진·텍스트 등 현재 범위의 개체 전체를 찾습니다. 종류 메뉴에서 모든 개체/도형/사진/텍스트 상자/선/그룹을 고를 수 있습니다. 유사 조건을 추가할 때만 PowerPoint에서 기준 개체 한 개를 선택합니다. 화면에 표시된 이전 선택이나 정렬용 기준 메뉴 대신 검색 요청 시 실제 선택을 읽습니다. 같은 개체 유형, 단색 채우기 색상, 크기 조건을 AND로 결합합니다. 같은 유형을 체크하지 않고 크기만 비교하면 도형과 사진도 함께 찾습니다. 색상은 자동 RGB 거리 기준(24), 크기는 기준 너비·높이 각각의 5%를 사용하되 1.5~18pt로 제한합니다. 화면 배율에 따라 달라지는 픽셀 대신 PowerPoint 좌표를 사용하며 사용자에게 수치 입력을 요구하지 않습니다. 이 값은 자동 휴리스틱이며 AI 의미 판별을 보장하지 않습니다. 기준 조건을 바꾼 경우 다시 검색합니다.

- 현재 슬라이드 또는 전체 프레젠테이션에서 검색할 수 있습니다. 텍스트 편집용 범위와 검색 범위를 따로 관리합니다. ‘찾아서 선택’을 누르면 해당 개체가 실제 PowerPoint에서 함께 선택됩니다. 결과 이름/ID 목록과 별도 선택 버튼은 없습니다.
- 현재 슬라이드 결과는 검색과 동시에 선택합니다. 전체 프레젠테이션 검색에서도 실제 선택은 현재 슬라이드에 한정하고 메시지에 전체 발견 개수와 현재 선택 개수를 구분합니다. 전체 검색 결과의 색상 변경/삭제는 범위·개수 확인 후 내부 대상 목록으로 실행합니다.
- 개체 유형은 `GeometricShape`, `TextBox`, `Image` 같은 큰 분류입니다. **현재 구현은 사각형과 화살표 같은 세부 프리셋 형태를 구분하지 않습니다.** API 1.5의 Shape에는 세부 도형 종류 읽기 기능이 없습니다. 향후 PPTX 자산 분석 방식은 별도로 검증해야 합니다.
- 그룹 내부 개체는 재귀 검색하지 않습니다. 단색이 아닌 채우기는 색상 조건에서 제외합니다.

## 텍스트·색상

선택 개체 / 현재 슬라이드 / 전체 프레젠테이션 중 범위를 고릅니다.

- 체크한 글꼴 이름·크기·색상만 변경하며 본문은 보존합니다. 균일하지 않은 글꼴 속성은 복사할 때 제외합니다.
- 찾기/바꾸기는 대소문자를 구분하는 명시적 문자열 치환입니다. 사용자가 입력한 문구 외의 날짜·수치는 자동 변경하지 않습니다. 텍스트 상자 전체 문자열을 갱신하므로 서로 다른 구간 서식이 유지되지 않을 수 있습니다.
- 색상 교체는 단색 채우기, 테두리, 균일한 글자 색상 중 기존 색과 일치하는 속성만 변경합니다. 알 수 없는 테마 색 이름은 비슷하다고 추정하지 않습니다.
- 표 셀, 그룹 내부, 이미지 내부 문자는 처리하지 않습니다. 텍스트 상자·기본 도형의 텍스트는 1.5에서 지원하며, placeholder의 텍스트 지원 여부 확인은 1.10의 `getTextFrameOrNullObject()`를 사용합니다. 이전 버전에서는 placeholder를 제외합니다.
- 기본 서식 복제는 단색 채우기·테두리 색/두께·균일한 텍스트 서식만 지원합니다. 그림자·그라데이션·투명도·자르기 서식의 완전한 복제는 포함하지 않습니다.

## 자료 보호

실행 직전에 대상 ID와 조회 당시 읽은 좌표·속성을 재확인합니다. 유사 검색은 조건에 필요한 속성만 읽으며 유형·크기 검색에서는 텍스트·글꼴·채우기·슬라이드 크기를 조회하지 않습니다. 텍스트 일괄 편집은 별도로 텍스트·서식을 읽어 보호합니다. 사용자가 다른 개체를 선택하거나 조회 이후 대상을 수정했으면 덮어쓰기를 중단합니다. 한 번에 최대 2,000개까지 조회/처리합니다. 전체 패치의 입력을 먼저 검증한 뒤 적용합니다. Office.js 배치는 데이터베이스 트랜잭션이 아니므로 호스트 오류 후 자동 롤백을 보장하지 않습니다.

## 남은 세부 기능

세부 프리셋 형태/선 굵기/투명도별 복합 검색, 그룹 내부 재귀 처리, 스마트 크롭, 사진 내용·설명·마킹 동시 교환, 이미지 원본 기반 교체, 그림자 등 고급 서식 복제는 미구현입니다. Phase 2 전체 세부 요구가 완료됐다는 의미로 이 버전을 표시하지 않습니다. AI 기능은 Phase 3 이후입니다.
